The mission

UE5 · C++ · MetaHuman · gRPC · MRQ

In-cabin simulation & synthetic dataset generation.

I build a real-time vehicle-interior (in-cabin) simulation tool in Unreal Engine 5. It configures MetaHuman avatars — clothing, hair, blend shapes and animations — inside virtual cabin environments, with controllable lighting and accident / distraction scenarios.

The app receives its configuration over gRPC (Protocol Buffers) and/or a UI, written to a json config that drives the scene. It then renders synthetic datasets via Movie Render Queue (MRQ) — used to train the cabin-sensing AI models behind automotive in-cabin cameras.

I work cross-functionally with the AI, data-analysis and sensor teams to make sure the generated data fits what the models actually need.

/03

XR — Apple Vision Pro

Unity 6 · PolySpatial · visionOS

Porting an interactive XR app to Apple Vision Pro.

My first mission, over the opening 3–4 months of the alternance: transposing an interactive Meta Quest XR app to Apple Vision Pro using Unity & PolySpatial in Hybrid mode — a real-time, interactive vehicle-interior customisation experience. I then moved onto the in-cabin simulation tool, where I've spent the rest of my time.

visionOS / PolySpatial is young, so much of the work was solving novel platform problems: Near/Far Interactor input, shader compatibility and rendering differences. I shared the solutions I found on the Unity community forums for other developers hitting the same walls.
